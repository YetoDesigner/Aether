# Aether

Coach cognitivo y emocional por voz. Un orbe que te escucha, te responde y te ayuda a alinear lo que **piensas**, **sientes** y **haces**.

## Cómo se usa

- **Mantén presionado el orbe** para hablar; al soltar, el coach te responde con voz.
- **Toca el orbe** para abrir el chat escrito.
- **Objetivos · Coach**: objetivos con fecha y hora, recordatorios y pasos de preparación; pulso anímico, check-ins de mañana, tarde y noche, y anillos de alineación.
- **Configuración**: voz del orbe, notificaciones y bloqueo de apps.

## Requisitos

- Navegador Chrome (recomendado) para reconocimiento y síntesis de voz.
- La página debe servirse por `https://` o `localhost` para usar el micrófono.

Los datos se guardan solo en el navegador (`localStorage`).

> Aether es una herramienta de autoconocimiento y hábitos. No hace diagnósticos ni reemplaza a un psicólogo.
